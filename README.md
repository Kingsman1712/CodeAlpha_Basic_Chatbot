# 🎯 Hangman Game (Python)

## 📌 Description
A simple text-based Hangman game built using Python.  
The player has to guess a randomly selected word one letter at a time before running out of attempts.

## 🚀 Features
- Random word selection from a predefined list
- Letter-by-letter guessing
- Maximum of 6 incorrect guesses
- Displays guessed letters
- Console-based gameplay

## 🛠️ Technologies Used
- Python 3

## 📚 Concepts Used
- Random module
- While loops
- If-else statements
- Strings
- Lists
- User input/output
