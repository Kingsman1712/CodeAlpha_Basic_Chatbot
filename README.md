# Basic Chatbot 🤖

## Description

This project is a simple **rule-based chatbot** developed using Python. The chatbot interacts with the user through text input and provides predefined responses based on specific keywords or phrases.

The program demonstrates the basic working of a chatbot by matching user messages with programmed responses and continuing the conversation until the user chooses to exit.

## Features

- Interactive text-based conversation
- Responds to basic greetings and questions
- Handles unknown inputs with a default response
- Allows continuous conversation
- Provides an exit option using a specific command

## Concepts Used

- Python functions
- Conditional statements
- Loops
- String manipulation
- User input handling
- Basic chatbot logic

## Program Workflow

- The user enters a message.
- The chatbot processes the input by converting it into lowercase.
- The input is compared with predefined responses.
- The chatbot returns an appropriate reply.
- The conversation continues until the user enters the exit command.

## Technologies Used

- **Programming Language:** Python

## Example Interactions

- Greeting messages receive a welcome response.
- Common questions receive predefined replies.
- Unknown messages receive a default response.
- Entering "bye" ends the conversation.
